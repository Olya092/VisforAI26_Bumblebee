Our task: 
CLIP prompt sensitivity: 
we attempted to investigate how does the wording of text prompt change CLIP's prediction. 
In Phase I, we give CLIP the same CIFAR-100 images with different sets of text prompts and visualise where predictions change, across categories and prompt types. For example we compared model's prediction under a simple baseline prompt “a photo of a dog” with its predictions under reworded prompts like “an image depicting a dog”.

Model: CLIP https://huggingface.co/docs/transformers/en/model_doc/clip

Dataset: CIFAR-100 https://cave.cs.toronto.edu/kriz/cifar.html
